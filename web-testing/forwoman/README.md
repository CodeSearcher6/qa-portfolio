# forwoman.com.ua — live client project

Manual testing of a live landing page, done for a real client on request.
The site is a registration funnel for a coaching programme; the only conversion
point is a sign-up form.

**Scope:** registration forms, contact links, desktop and mobile layout.
**Out of scope:** payment integration, analytics accuracy, content.

**Result:** 6 defects found, one of them blocking the primary conversion flow
on desktop.

| File | For whom |
|---|---|
| [bug-reports.md](bug-reports.md) | Technical reports — steps to reproduce, severity, priority, recommendations |
| [client-report.md](client-report.md) | Plain-language summary for the business owner, prioritised by what to fix first |

## What made this different from a practice project

The client is not technical and had no way to act on a raw list of bugs. So the
work was delivered as two documents: a technical one for whoever implements the
fixes, and a prioritised summary explaining what each defect costs the business
and what to fix first.
